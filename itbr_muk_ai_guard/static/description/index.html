ServIAm Guard

Approval on every AI write, admin-only switch, no web access, API keys off the database

Guard rails for the MuK AI assistant (shown as ServIAm in Portuguese). Each one is a switch under Settings > MuK AI > Guard, all on after installation.

  • Approve every write: every create, update, delete or action the assistant runs waits for the user's approval, on any model.
  • Only admins turn approvals off, in a chat or on an agent.
  • Block web access: no web search or page fetch, so text planted in a record cannot make the assistant send data to an outside address.
  • API keys off the database: read from ODOO_AI_KEY_<PROVIDER> or the ai_key_<provider> option of the Odoo configuration file, so backups and restored copies never carry them.

Odoo access rights and record rules still apply: the assistant acts as the user who is chatting.
